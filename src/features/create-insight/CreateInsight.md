Из-за того что у нас есть создание инсайта и редактирование инсайта, мы сделали общую форму `InsightForm` в сущностях.
`CreateInsight` - хранит в себе лишь логику добавления инсайта через RTK (потом там будет запрос на бэкенд) и message с текстом "Инсайт успешно создан"

## Вот что он делает конкретно

Сам CreateInsight отвечает только за создание сущности:

1. Получает данные формы.
2. Генерирует ID.
3. Устанавливает даты.
4. Отправляет addInsight в Redux.
5. Показывает уведомление.
