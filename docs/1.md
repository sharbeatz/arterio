Создание проекта

```bash
npm create vite@latest arterio -- --template react-ts
cd arterio
npm install
```

Устанавливаем необходимые библиотеки

```bash
npm install @reduxjs/toolkit react-redux redux-persist react-router-dom antd @ant-design/icons
```

Для SCSS Modules:

```bash
npm install -D sass
```

```bash
npm install -D prettier
```
